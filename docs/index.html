Quelo Audiomaker

Un piccolo studio di produzione audio portatile su chiavetta USB — live e installabile, in italiano. Ispirato al personaggio «Quelo» di Corrado Guzzanti e derivato da Quelo Office: solidità di Debian GNU/Linux + desktop leggero LXQt + Openbox.

In evidenza

Live e installabile — salvataggio / ripristino sessione

  • Live da USB: ogni boot riparte dall’immagine ISO pulita (cache/temp in RAM).
  • Salvataggio selettivo allo spegnimento: scegli cosa conservare (rete, desktop, audio, Firefox, Mixxx, Ardour, REAPER, BUTT, FFADO…).
  • Installabile su disco con Calamares (LightDM); live e installata restano separate.
  • Dati su QUELO-HOME (exFAT), leggibile anche da Windows e macOS.

REAPER (Cockos)

Incluso REAPER (menu REAPER - Editor Audio Pro). Si può usare anche senza acquistare subito la licenza: dopo circa 60 giorni compare un avviso, ma continua a funzionare al 100% (solo un reminder). Si invita a sostenere Cockos: https://www.reaper.fm/

Quelo-palinsesto-radio

Scheduler/player radio settimanale incluso (**menu PALINSESTO RADIO**): file, PLAYLIST (m3u/pls), LIVE, LINK (http/https), ANTI BIANCO, silence-gate, SETTING, zoom timeline.

  • Calendario lunedì–domenica × 24 ore; etichetta 24:00.
  • Failover e ripresa dalla posizione interrotta; DB .palinsesto.db su QUELO-HOME / $HOME.
Scarica manuale

PDF del manuale Quelo-palinsesto-radio (stessa icona del Desktop).

A cosa serve

  • portare un kit audio (DAW, DJ/podcast, streaming, palinsesto, codec, plugin);
  • lavorare su più PC con la stessa chiavetta;
  • file personali leggibili anche da Windows e macOS;
  • installare su disco quando serve un sistema fisso.

Oppure: 1) Scarica le 2 parti da GitHub

GitHub non accetta file > 2 GB: l’ISO (~2,3 GB) è in 2 pezzi. Release 0.08-alpha.

1 · part00 2 · part01 sha256 (opz.)

2) Unisci le parti → ottieni l’ISO

Serve solo se hai scaricato le 2 parti da GitHub (non se hai preso l’ISO intera dal mirror). Metti nella stessa cartella i file .part00, .part01 e lo script JOIN, poi scegli un metodo. Istruzioni anche in README-ISO-0.08-alpha.txt.

Metodo A — script (più semplice)

Scarica .bat (Windows) Scarica .sh (Linux)
  • Windows: salva il .bat nella cartella delle parti, poi doppio clic su JOIN-ISO-0.08-alpha.bat. Se Windows blocca lo script: «Altre informazioni» → «Esegui comunque».
  • Linux: salva lo .sh nella cartella delle parti, apri un terminale lì e digita: bash JOIN-ISO-0.08-alpha.sh
  • Alla fine compare il file Quelo-Audiomaker-0.08-alpha.iso nella stessa cartella.

Metodo B — un comando nel terminale

Apri il terminale nella cartella dove hai le 2 parti e incolla una di queste righe:

Windows (Prompt dei comandi):

copy /b Quelo-Audiomaker-0.08-alpha.iso.part00 + Quelo-Audiomaker-0.08-alpha.iso.part01 Quelo-Audiomaker-0.08-alpha.iso

Linux / macOS:

cat Quelo-Audiomaker-0.08-alpha.iso.part* > Quelo-Audiomaker-0.08-alpha.iso

prepare-usb (preparazione chiavetta)

Dopo che avrai l’ISO fatta puoi procedere con questo passaggio:

prepare-usb scrive l’ISO sulla chiavetta e crea le partizioni persistence + QUELO-HOME (stesso schema di Quelo Office / Videomaker). Esegui sempre dal PC host, mai dalla live avviata sulla stessa USB.

Come usarlo

  1. Estrai l’archivio scaricato.
  2. Avvia prepare-usb sul PC host (istruzioni sotto, a seconda del sistema).
  3. Nella GUI scegli l’ISO Quelo-Audiomaker-0.08-alpha.iso, la chiavetta USB e la dimensione di persistenza; conferma digitando SI SCRIVI.
  4. Quando ha finito, riavvia il PC e avvia dalla chiavetta (BIOS/UEFI).

Linux — GUI (consigliata)

Pacchetto completo:

cd Quelo_prepare_usb
./prepare-usb-gui.sh

Oppure pacchetto solo GUI:

cd Quelo_prepare_usb_gui
./prepare-usb-gui.sh

Prerequisiti (Debian/Ubuntu): sudo apt install python3 python3-tk e2fsprogs exfatprogs util-linux polkit-1

Linux — terminale (CLI)

cd Quelo_prepare_usb
sudo ./prepare-usb.sh

Windows — GUI

  1. Estrai lo ZIP / RAR / TAR.
  2. Doppio clic su AVVIA.bat (accetta UAC amministratore).
  3. Scegli ISO Audiomaker, chiavetta USB, persistenza; digita SI SCRIVI.

Pacchetto offline (include Python 32 bit). Serve Windows 7 SP1 o superiore e privilegi amministratore.
