Quelo Audiomaker

Un piccolo studio di produzione audio portatile su chiavetta USB — in italiano, pronto all’uso su quasi qualsiasi PC. Ispirato al personaggio «Quelo» di Corrado Guzzanti e derivato da Quelo Office: solidità di Debian GNU/Linux + desktop leggero LXQt + Openbox, con strumenti per registrazione, editing e mix audio.

A cosa serve

Quelo Audiomaker è pensata per chi vuole:

  • portare con sé un kit audio (editor, player, conversione/codec);
  • lavorare su più PC con la stessa chiavetta, senza toccare i dischi interni;
  • avere file personali e media leggibili anche da Windows e macOS (partizione home in exFAT);
  • installare Quelo Audiomaker su un disco (interno o esterno) con Calamares;
  • salvare solo le configurazioni che interessano (rete, stampanti, desktop, audio, schermo, Firefox, Audacity, Audacious, Mixxx…), senza trasformare la live in un sistema opaco.

Novità nella 0.08-alpha

Prima release pubblica di Quelo Audiomaker. Il changelog resta vuoto fino alla pubblicazione formale.

  • Studio audio live: Mixxx (DJ set / podcast), Audacity, Audacious, FFmpeg, PulseAudio.
  • Firmware audio per molte schede laptop/USB (SOF, Intel sound, Cirrus, UCM).
  • Installer Calamares (wizard disco / partizioni / HOME exFAT o ext4).
  • Sistema installato: login con LightDM; live e installata restano separate.

Caratteristiche principali

Sistema e desktop

  • Basata su Debian sid (live-build), locale italiano, fuso orario Europe/Rome.
  • Live: avvio diretto al desktop (autologin, startx, LXQt + Openbox).
  • Installata: login con LightDM.
  • Installer Calamares dal menu live.
  • Menu applicazioni personalizzato (fisso). Guida: HOW-TO-menu-config.txt.
  • Menu GRUB con voci Quelo Audiomaker (anche multi-kernel: Quelo-Audiomaker, kernel …).
  • Due pannelli LXQt: in alto versione / RAM (+ swap ZRAM) / spazio home / orologio; in basso menu, taskbar, rete, Bluetooth, batteria/AC, volume, cestino, spegnimento.
  • Icona HOME sul Desktop verso QUELO-HOME.
  • Menu personalizzato con logo Quelo; caratteri regolabili per menu e pannello inferiore.
  • Risoluzione e multi-monitor con lxrandr (wrapper quelo-lxrandr).

Memoria

  • ZRAM: circa 50% della RAM, compressione lz4, niente file di swap sulla USB.
  • Incluso stress-ng per prove sotto carico.

Hardware e connettività

  • Ampia copertura firmware di rete.
  • Stampanti di rete e USB (Avahi/mDNS, ipp-usb; driver Gutenprint e HP).
  • Scanner via SANE (anche airscan).
  • Bluetooth con applet nel pannello.
  • Batteria / alimentazione AC nel tray.
  • Condivisioni di rete Samba/CIFS con SMB4K.

Comportamento live

  • Ogni avvio riparte dall’immagine ISO pulita (niente overlay Debian automatico su /usr).
  • Cache e temporanei in RAM.
  • Salvataggio selettivo della sessione: rete, stampanti, Bluetooth, desktop, audio, schermo, Firefox, Audacity, Audacious, Mixxx, gestione energia.
  • Dati utente e media sulla partizione QUELO-HOME (exFAT), montata automaticamente.

Requisiti consigliati (RAM)

Chiavetta USB: consigliata USB 3 o superiore e 64 GB o più, per avere spazio sufficiente a salvare sulla stessa chiavetta file, media e progetti (partizione QUELO-HOME).

ZRAM (50% RAM, lz4, swappiness 30) aiuta le macchine con poca RAM.

Layout della chiavetta USB

Dopo la preparazione con prepare-usb (stesso schema di Quelo Office):

┌─────────────────────────────────────────────────────────┐
│  Partizione 1–2  │  ISO live (sola lettura al boot)     │
├──────────────────┼──────────────────────────────────────┤
│  Partizione 3    │  ext4 «persistence» — config Linux   │
│                  │  (invisibile a Windows/macOS)        │
├──────────────────┼──────────────────────────────────────┤
│  Partizione 4    │  exFAT «QUELO-HOME» — i tuoi file    │
│                  │  (leggibile ovunque)                 │

Oppure: 1) Scarica le 2 parti da GitHub

GitHub non accetta file sopra i 2 GB, quindi l’ISO (~2,3 GB) è divisa in 2 pezzi. Scaricali entrambi nella stessa cartella (il file sha256 è facoltativo, serve solo per controllare che il download sia integro). Release: 0.08-alpha.

1 · part00 2 · part01 sha256 (opz.)

2) Unisci le parti → ottieni l’ISO

Serve solo se hai scaricato le 2 parti da GitHub (non se hai preso l’ISO intera dal mirror). Scegli un solo metodo. Il più semplice è scaricare lo script per il tuo sistema e metterlo nella stessa cartella delle 2 parti.

Metodo A — script (consigliato)

Scarica .bat (Windows) Scarica .sh (Linux)
  • Windows: doppio clic su JOIN-ISO-0.08-alpha.bat. Se compare un avviso, scegli «Altre informazioni» → «Esegui comunque».
  • Linux: apri un terminale nella cartella e digita: bash JOIN-ISO-0.08-alpha.sh
  • Alla fine trovi il file Quelo-Audiomaker-0.08-alpha.iso.

Metodo B — un comando nel terminale

Apri il terminale nella cartella dove hai le 2 parti, poi copia-incolla una di queste righe:

Windows (Prompt dei comandi):

copy /b Quelo-Audiomaker-0.08-alpha.iso.part00 + Quelo-Audiomaker-0.08-alpha.iso.part01 Quelo-Audiomaker-0.08-alpha.iso

Linux / macOS:

cat Quelo-Audiomaker-0.08-alpha.iso.part* > Quelo-Audiomaker-0.08-alpha.iso

prepare-usb (preparazione chiavetta)

Dopo che avrai l’ISO puoi preparare la chiavetta dal PC host (mai dalla live avviata sulla stessa USB).

prepare-usb scrive l’ISO sulla chiavetta e crea le partizioni persistence + QUELO-HOME (stesso schema di Quelo Office / Videomaker — script già adatti).

Linux — GUI (dal repo)

cd USB_SOURCE_CODE/Quelo_prepare_usb
./prepare-usb-gui.sh

Prerequisiti (Debian/Ubuntu): sudo apt install python3 python3-tk e2fsprogs exfatprogs util-linux polkit-1

Windows — GUI (da Quelo Office 0.71)

Stesso layout di partizioni, compatibile con questa ISO:

ZIP RAR TAR
  • Estrai, avvia la GUI come amministratore.
  • Nella GUI scegli l’ISO Quelo-Audiomaker-0.08-alpha.iso, la chiavetta USB e la dimensione di persistenza; conferma digitando SI SCRIVI.
