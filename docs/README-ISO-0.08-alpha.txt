Quelo Audiomaker 0.08-alpha — ISO spezzata (GitHub)
===================================================

GitHub non accetta file > 2 GB. L’ISO (~2,3 GB) è in 2 parti.

1) Scarica nella stessa cartella:
   - Quelo-Audiomaker-0.08-alpha.iso.part00
   - Quelo-Audiomaker-0.08-alpha.iso.part01
   - Quelo-Audiomaker-0.08-alpha.iso.sha256 (opzionale)
   - JOIN-ISO-0.08-alpha.bat (Windows) oppure JOIN-ISO-0.08-alpha.sh (Linux)

2) Unisci:
   Windows: doppio clic su JOIN-ISO-0.08-alpha.bat
   Linux:   bash JOIN-ISO-0.08-alpha.sh

   Oppure un comando:
   Windows:
     copy /b Quelo-Audiomaker-0.08-alpha.iso.part00 + Quelo-Audiomaker-0.08-alpha.iso.part01 Quelo-Audiomaker-0.08-alpha.iso
   Linux/macOS:
     cat Quelo-Audiomaker-0.08-alpha.iso.part* > Quelo-Audiomaker-0.08-alpha.iso

3) Preferisci un solo file già pronto?
   https://click2all.org/iso/Quelo-Audiomaker-0.08-alpha.iso

Release: https://github.com/alby-quelo/Quelo-Audiomaker/releases/tag/0.08-alpha
