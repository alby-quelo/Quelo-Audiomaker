Quelo Audiomaker

A small portable audio production studio on a USB stick — live and installable, in Italian. Inspired by Corrado Guzzanti’s «Quelo» and derived from Quelo Office: Debian GNU/Linux + lightweight LXQt + Openbox.

Download full ISO 0.08-alpha GitHub parts / instructions Source code

Highlights

Live and installable — selective session save / restore

  • Live from USB: every boot starts from a clean ISO image.
  • Selective save on shutdown: keep only what you choose.
  • Installable to disk with Calamares; live and installed stay separate.
  • Data on QUELO-HOME (exFAT), readable on Windows and macOS.

REAPER (Cockos)

Includes REAPER. You can use it without buying a license immediately: after about 60 days a nag dialog appears, but it keeps working at 100%. Please support Cockos: https://www.reaper.fm/

Quelo-palinsesto-radio

Weekly radio schedule player (**PALINSESTO RADIO**): files, PLAYLIST, LIVE, LINK, ANTI BIANCO, silence-gate, SETTING, timeline zoom.

Download full ISO 0.08-alpha

Or: 1) Download the 2 parts from GitHub

GitHub rejects files over 2 GB, so the ISO (~2.3 GB) is split into 2 parts. Download both into the same folder. Release: 0.08-alpha.

1 · part00 2 · part01 sha256 (opt.)

2) Join the parts → get the ISO

Needed only if you downloaded the 2 GitHub parts (not the full mirror ISO). Put .part00, .part01 and the JOIN script in the same folder, then pick one method. Also see README-ISO-0.08-alpha.txt.

Method A — script (easiest)

Download .bat (Windows) Download .sh (Linux)
  • Windows: save the .bat next to the parts, then double-click JOIN-ISO-0.08-alpha.bat. If Windows blocks it: “More info” → “Run anyway”.
  • Linux: save the .sh next to the parts, open a terminal there and run: bash JOIN-ISO-0.08-alpha.sh
  • When finished you get Quelo-Audiomaker-0.08-alpha.iso in that folder.

Method B — one terminal command

Open a terminal in the folder with the 2 parts and paste one of these lines:

Windows (Command Prompt):

copy /b Quelo-Audiomaker-0.08-alpha.iso.part00 + Quelo-Audiomaker-0.08-alpha.iso.part01 Quelo-Audiomaker-0.08-alpha.iso

Linux / macOS:

cat Quelo-Audiomaker-0.08-alpha.iso.part* > Quelo-Audiomaker-0.08-alpha.iso
