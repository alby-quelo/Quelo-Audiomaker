Quelo Audiomaker

A small portable audio production studio on a USB stick — Italian locale, ready on almost any PC. Inspired by Corrado Guzzanti’s «Quelo» and derived from Quelo Office: Debian GNU/Linux reliability + lightweight LXQt + Openbox, with tools for recording, editing and mixing audio.

What it is for

Quelo Audiomaker is aimed at people who want to:

  • carry an audio toolkit (editor, player, conversion/codecs);
  • work on multiple PCs with the same USB stick, without touching internal disks;
  • keep personal files and media readable on Windows and macOS (exFAT home partition);
  • install Quelo Audiomaker on a disk (internal or external) with Calamares;
  • save only the settings that matter (network, printers, desktop, audio, display, Firefox, Audacity, Audacious, Mixxx…), without turning the live system into an opaque installation.

What’s new in 0.08-alpha

First public Quelo Audiomaker release. The changelog stays empty until formal publication.

  • Live audio studio: Mixxx (DJ set / podcast), Audacity, Audacious, FFmpeg, PulseAudio.
  • Audio firmware for many laptop/USB cards (SOF, Intel sound, Cirrus, UCM).
  • Calamares installer (disk / partitions / HOME exFAT or ext4 wizards).
  • Installed system: login with LightDM; live and installed stay separate.
  • Desktop with Mixer Dj / Podcast icon; fixed Openbox menu. How-to: HOW-TO-menu-config.txt.

Main features

System and desktop

  • Based on Debian sid (live-build), Italian locale, Europe/Rome timezone.
  • Live: boots straight to the desktop (autologin, startx, LXQt + Openbox).
  • Installed: login with LightDM.
  • Calamares installer from the live menu.
  • Custom application menu (fixed). How-to: HOW-TO-menu-config.txt.
  • GRUB menu branded Quelo Audiomaker (including multi-kernel: Quelo-Audiomaker, kernel …).
  • Two LXQt panels: top — version / RAM (+ ZRAM swap) / home space / clock; bottom — menu, taskbar, network, Bluetooth, battery/AC, volume, trash, power.
  • Desktop HOME icon to QUELO-HOME.
  • Custom Quelo menu; adjustable fonts for menu and bottom panel.
  • Display layout via lxrandr (quelo-lxrandr wrapper).

Memory

  • ZRAM: about 50% of RAM, lz4 compression, no swap file on the USB stick.
  • stress-ng included for load tests.

Display drivers: NVIDIA (nvidia-driver) and AMD firmware (firmware-amd-graphics) where needed for the screen.

Hardware and connectivity

  • Broad network firmware coverage.
  • Printers over network and USB (Avahi/mDNS, ipp-usb; Gutenprint and HP drivers).
  • Scanners via SANE (including airscan).
  • Bluetooth panel applet.
  • Battery / AC in the tray.
  • Network shares (Samba/CIFS) via SMB4K.

Live behaviour

  • Every boot starts from a clean ISO image (no automatic Debian-style overlay on /usr).
  • Caches and temp data in RAM.
  • Selective session save: network, printers, Bluetooth, desktop, audio, display, Firefox, Audacity, Audacious, Mixxx, power management.
  • User data and media on the QUELO-HOME exFAT partition, auto-mounted.

USB stick: USB 3 or newer and 64 GB or more recommended, so you have enough room on the same stick for files, media and projects (QUELO-HOME partition).

ZRAM (50% of RAM, lz4, swappiness 30) helps low-RAM machines.

USB stick layout

After preparation with prepare-usb (same scheme as Quelo Office):

┌─────────────────────────────────────────────────────────┐
│  Partitions 1–2  │  Live ISO (read-only at boot)        │
├──────────────────┼──────────────────────────────────────┤
│  Partition 3     │  ext4 «persistence» — Linux config   │
│                  │  (invisible to Windows/macOS)        │
├──────────────────┼──────────────────────────────────────┤
│  Partition 4     │  exFAT «QUELO-HOME» — your files     │
│                  │  (readable everywhere)               │
└─────────────────────────────────────────────────────────┘

Download ISO

Full ISO (recommended)

One ready file, no joining required. Mirror: click2all.org.

Download full ISO 0.08-alpha

Or: 1) Download the 2 parts from GitHub

GitHub rejects files over 2 GB, so the ISO (~2.3 GB) is split into 2 parts. Download both into the same folder (sha256 is optional — only to verify integrity). Release: 0.08-alpha.

1 · part00 2 · part01 sha256 (opt.)

2) Join the parts → get the ISO

Needed only if you downloaded the 2 GitHub parts (not the full mirror ISO). Pick one method. Easiest: download the script for your OS into the same folder as the 2 parts.

Method A — script (recommended)

Download .bat (Windows) Download .sh (Linux)
  • Windows: double-click JOIN-ISO-0.08-alpha.bat. If a warning appears, choose “More info” → “Run anyway”.
  • Linux: open a terminal in the folder and run: bash JOIN-ISO-0.08-alpha.sh
  • When finished you get Quelo-Audiomaker-0.08-alpha.iso.

Method B — one terminal command

Open a terminal in the folder with the 2 parts, then paste one of these lines:

Windows (Command Prompt):

copy /b Quelo-Audiomaker-0.08-alpha.iso.part00 + Quelo-Audiomaker-0.08-alpha.iso.part01 Quelo-Audiomaker-0.08-alpha.iso

Linux / macOS:

cat Quelo-Audiomaker-0.08-alpha.iso.part* > Quelo-Audiomaker-0.08-alpha.iso

prepare-usb (USB preparation)

Once you have the ISO, prepare the stick from the host PC (never from the live system booted from the same USB).

prepare-usb writes the ISO and creates persistence + QUELO-HOME (same layout as Quelo Office / Videomaker — scripts already suitable).

Linux — GUI (from the repo)

cd USB_SOURCE_CODE/Quelo_prepare_usb
./prepare-usb-gui.sh

Host prerequisites (Debian/Ubuntu): sudo apt install python3 python3-tk e2fsprogs exfatprogs util-linux polkit-1

Windows — GUI (from Quelo Office 0.71)

Same partition layout, compatible with this ISO:

ZIP RAR TAR
  • Extract, run the GUI as administrator.
  • Choose Quelo-Audiomaker-0.08-alpha.iso, the USB stick and persistence size; confirm with SI SCRIVI.
